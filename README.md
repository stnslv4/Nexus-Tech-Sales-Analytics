# Nexus-Tech-Sales-Analytics
Interactive Power BI Dashboard for Sales and Profitability Analysis

Sales & Profitability Analysis Dashboard — Nexus Tech
📌 Огляд проекту
Цей дашборд створений для комплексного аналізу фінансових показників компанії Nexus Tech. Основна мета — надати бізнесу інструмент для моніторингу ключових метрик (KPI), аналізу динаміки продажів та виявлення найбільш прибуткових сегментів і продуктів.

🛠 Технологічний стек
Інструмент візуалізації: Power BI Desktop.

Обробка даних: Power Query (очищення, зміна типів даних, створення ієрархій).

Аналітика: DAX (створення мір для обчислення прибутку, маржі та середнього чека).

📊 Основні блоки дашборду
KPI-панель: Відображає загальний виторг ($2,30 млн), кількість замовлень, чистий прибуток та середній чек.

Часовий аналіз:

Динаміка виторгу за місяцями: Дозволяє відстежувати сезонні коливання.

Порівняння річних показників: Наочна лінійна діаграма для порівняння ефективності різних років.

Структурний аналіз:

Рейтинг регіонів: Карта/стовпчикова діаграма продажів по штатах.

Продажі за категоріями: Аналіз товарних груп (Technology, Furniture, Office Supplies).

Деталізація та інсайти:

Топ-продукт за прибутком: Динамічна картка, що підсвічує найбільш вигідний товар (наприклад, Canon imageCLASS 2200).

Зведена таблиця: Детальні дані по роках з показниками прибутку та обсягу замовлень.

💡 Ключові висновки (Insights)
Найбільш прибутковою категорією є Technology, попри те, що за обсягом замовлень вона може поступатися іншим сегментам.

Виявлено стійку тенденцію до зростання виторгу в останньому кварталі року (сезонність).

Середній чек стабільний і становить приблизно $229,86, що є важливим орієнтиром для маркетингових компаній.

📂 Як переглянути
Ви можете завантажити файл .pbix з цього репозиторію та відкрити його в Power BI Desktop для ознайомлення з інтерактивними функціями.

### 🧠 Приклади використаних DAX-мір

Для розрахунку ключових показників було створено наступні міри:

**1. Чистий прибуток (Total Profit):**
TotalProfit = SUM('Orders'[Profit])

**2. Рівень маржинальності (Profit Margin):**
Profit Margin = DIVIDE([Total Profit], [Total Sales], 0)

**3. Темп росту продажів (Sales Growth %):**
Sales Growth % = DIVIDE([Total Sales] - [Sales Last Month], [Sales Last Month], 0)
